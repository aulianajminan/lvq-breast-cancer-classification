# Breast Cancer Classification using LVQ
A classification analysis using the Learning Vector Quantization (LVQ) method on the Breast Cancer Wisconsin (Diagnostic) dataset.

## Analysis
The analysis covers:
* Data preprocessing
* LVQ model implementation
* Classification results
* Model evaluation

## Dataset
Breast Cancer Wisconsin (Diagnostic) dataset obtained from Kaggle.
